# Submission draft

## Project description (approximately 200 words)

Community services can correct a phone number, replace an email address, or
remove an old website while the rest of the web keeps sharing it. Someone
looking for food, shelter or help after a disaster can still reach the wrong
place. Streetli Ghost Links makes that gap visible and gives reviewers a way
to act on evidence.

The dashboard begins with a live, narrow projection of Streetli's retained
corrections and automated flags. A person can browse the queue or describe what
they want to investigate. You.com searches for the old identifier and fetches
current public pages. CrewAI coordinates bounded research tasks using Parasail
for request interpretation and evidence verification. Code checks provider
identity, exact quotations and observation time before a finding is displayed.
Uncertain results stay uncertain.

Reviewers can inspect the original service context, open correction guidance,
and deliberately use One to send a Gmail progress report. Other One actions
are available when their destination accounts are configured. The app does not
automatically submit abuse reports or claim a correction was accepted.

The public repository contains the new dashboard, contracts, prompts and
integrations. Streetli's existing dataset and internal cleanup systems predate
the hackathon. Real research replaces a static demo, while synthetic fixtures
remain available for reproducible offline development.

## Partner integrations

- **You.com Search and Contents:** discover public references and retrieve pages
  for verification. Search snippets alone never establish a current error.
- **CrewAI:** coordinate routing, planning and verification tasks with structured
  results and visible progress.
- **Parasail:** run the configured model for request interpretation, case
  selection and evidence judgments. Output still passes application evidence gates.
- **One:** resolve connected actions and, on an explicit reviewer click, send
  Gmail progress reports or service lists. Gmail is connected in the hosted app;
  Sheets still needs a target spreadsheet, and Discord/Twilio need connections.
